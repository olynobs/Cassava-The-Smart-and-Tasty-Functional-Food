# Cassava-The-Smart-and-Tasty-Functional-Food
Cassava: The Smart &amp; Tasty Functional Food is a single-file interactive web page that presents cassava as a smart, healthy alternative to rice. It combines a cassava-vs-rice comparison, a customizable mascot, a carbohydrate calculator, a quiz, and a built-in game, Cassava Quest, that teaches low-GI food choices through play.
